Reliability tests cover live/pre-existing arrays, released objects and views,
logical shared sizes, repeated identities and ID reuse, unrelated versus related
dtypes, true caller locations, nested restoration, concurrent worker sessions,
explicit worker attachment, async context inheritance/cancellation, application
exceptions including BaseException, external tracer depth/peak preservation,
external tracing stop, signed net change, invalid inputs, and snapshot mutation.
Coverage is a regression signal, not proof of universal detector accuracy.

Local generated artifacts are outside the checkout at `/workspace/.setup/RNPY`:
`v04-benchmarks.json`, `v04-build.log`, `v04-dist/`, the independent
`v04-wheel-env/`, and its coverage database. Raw benchmark samples include
runtime metadata and separate traced/logical metrics. They are not universal
speed claims or statistically significant regression baselines.

## Remaining limits and next gate

No required local checks are failing. Hosted Python 3.10/3.11/3.13/3.14,
minimum NumPy 1.23.5, Windows, and macOS jobs remain unrun here; CI must establish
those combinations before a release candidate is accepted.

Temporary-buffer allocations remain unmeasured. Dtype source relationships are
caller assertions; repetition is a registration pattern, not proof of waste.
Traced memory is process-wide and includes instrumentation/unrelated work;
overlap and external tracing prevent interval-peak attribution. External
stop/restart/peak-reset interference is unsupported. Long sessions retain
metadata proportional to unique registrations until results are reset/replaced.
RSS, native allocation coverage, NumPy-domain-only snapshots, automatic
provenance, a profiling CLI/report schema, and optimization validation are not
implemented in this phase.

Next: run the configured CI matrix, review the documented compatibility
corrections, then start v0.5 with controlled NumPy-domain snapshot/diff
experiments and explicit accuracy/overhead acceptance tests. Package publication,
public releases, and merging into main still require maintainer approval.
